# show-sheet

Light-mode take on a run-of-show sheet app. One event screen with a status timeline, and the three-dot menu pops open into Share and Customize Sheet panels that spring in from the corner.

Expo 57, Reanimated, SVG, NativeWind.

## Run

```
npm install
npx expo start
```

Banner and avatar images load from Unsplash and Pravatar, so it needs a network connection.
