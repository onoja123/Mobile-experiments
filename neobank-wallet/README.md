# neobank-wallet

![neobank-wallet demo](demo.gif)

Two cards peek up from the bottom edge like they're sitting in a wallet. Tap one and the dark card rides up to the header while the white one slides down and out, the hero copy fades off, and the transaction list rises in behind it.

It's all one 0→1 value with each element reading a different window of it, so the pieces hand off rather than move together. Closing runs a shorter curve than opening, so dismissal feels quicker than the reveal.

Expo 57, expo-router, Reanimated, Gesture Handler, SVG, NativeWind.

## Run

```
npm install
npx expo start
```
