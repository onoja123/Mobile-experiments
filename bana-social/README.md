# Bana

Recreation of a social trading wallet design by @akwaabaaa — a dark wallet
profile with balance, actions and a leveraged token list, and a group chat
where the boys ape into $Bana together: reactions, a trade receipt card, and
an emoji-only reply.

Two screens wired with expo-router; the chat tab on the wallet opens the
group chat.

```
npm install
npx expo start
```
