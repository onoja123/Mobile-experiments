# hotel-booking

![hotel-booking demo](demo.gif)

A hotel search sheet where the Search button does the talking. Press it and the pill collapses into a circle, spins while it looks, pops a checkmark, then re-expands into a wide summary of what it found. If the search fails it shakes it off and puts the label back.

The price slider is a demand histogram — drag a thumb and the bars flip colour in a ripple spreading out from your finger, while the price readout eases along behind rather than flickering on every pixel of drag. Picking dates washes the highlight across the range a day at a time.

Expo 57, expo-router, Reanimated, Gesture Handler, expo-blur, NativeWind.

## Run

```
npm install
npx expo start
```
