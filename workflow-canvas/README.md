# workflow-canvas

![workflow-canvas demo](demo.gif)

Mobile UI for a workflow automation tool — a node canvas with an integration rail, plus templates, org overview and usage screens. The menu button opens a dark full-screen nav that marks where you are and pushes you wherever you tap.

This one's a layout study rather than a motion study. The canvas is hand-placed at 390pt and every node, connector, icon and offset multiplies by a single scale factor, so it keeps its proportions on any screen instead of reflowing.

Expo 54, expo-router, NativeWind.

## Run

```
npm install
npx expo start
```
