# Mono Bank

Minimal banking UI. White paper, hairline grids, Space Grotesk. Three screens: wallet home with lilac/butter debit cards and transactions, a send-money keypad with a blinking cursor, and monthly statistics with an animated donut chart.

The + button opens Send money, the arrows button opens Monthly statistic.

## Run

```
npm install
npx expo start
```

Expo SDK 57, NativeWind, Reanimated, react-native-svg.
